# تشغيل النظام أوفلاين + نسخ احتياطي تلقائي للسحابة

هذه السكربتات تجعل النظام يعمل بشكل كامل بدون إنترنت على جهاز الفندق، وترفع
نسخة احتياطية تلقائياً إلى OneDrive/Google Drive كلما توفر الإنترنت.

## الفكرة

- التطبيق يعمل محلياً 24 ساعة عبر Apache كخدمة Windows دائمة (`HotelOsammaApache`)
  ولا يحتاج إنترنت إطلاقاً للعمل اليومي.
- كل ساعة، مهمة مجدولة تأخذ لقطة آمنة من قاعدة البيانات (لا تتأثر حتى لو كان
  أحد يستخدم النظام في نفس اللحظة) وتضعها في مجلد OneDrive/Google Drive.
- برنامج OneDrive/Google Drive نفسه يتكفّل برفعها للسحابة تلقائياً بمجرد
  توفر الإنترنت — لا حاجة لأي منطق "كشف اتصال" مخصص، وهذا أكثر أماناً وموثوقية.
- النسخة الأونلاين تبقى **نسخة احتياطية فقط** ولا يُكتب عليها مباشرة، فلا يوجد
  خطر تعارض بيانات.

## الملفات

| الملف | الوظيفة |
|---|---|
| `backup_snapshot.php` | يأخذ لقطة متسقة وآمنة من `database.sqlite` باستخدام أمر `VACUUM INTO` (لا يفسد البيانات حتى أثناء الكتابة عليها) |
| `backup_to_cloud.ps1` | ينسّق عملية النسخ الكامل: قاعدة البيانات + مجلد المرفقات (`storage/app/private`) → ملف zip بالتاريخ والوقت → مجلد OneDrive/Google Drive تلقائياً. يحتفظ بآخر 20 نسخة فقط ويحذف الأقدم |
| `install_scheduled_backup.ps1` | **شغّله مرة واحدة فقط** بعد تثبيت المشروع على جهاز العميل — يسجّل مهمة Windows مجدولة تُشغّل `backup_to_cloud.ps1` كل ساعة تلقائياً |
| `create_desktop_shortcut.ps1` | **شغّله مرة واحدة فقط** — ينشئ اختصار "نظام الفندق" على سطح مكتب العميل يفتح `http://localhost` مباشرة في المتصفح. هذا كل ما يحتاج العميل الضغط عليه |

## خطوات التثبيت على جهاز العميل (مرة واحدة فقط)

بعد اتباع دليل التثبيت الأساسي (PHP 8.3 + Laragon + git clone + composer +
npm + migrate + استيراد البيانات + خدمة Apache)، نفّذ من داخل PowerShell:

```powershell
cd C:\laragon\www\hotel_osamma\deploy
powershell -ExecutionPolicy Bypass -File create_desktop_shortcut.ps1
powershell -ExecutionPolicy Bypass -File install_scheduled_backup.ps1
```

بعدها لا يحتاج العميل فعل أي شيء — فقط الضغط على اختصار "نظام الفندق" على
سطح المكتب، والنظام يعمل والنسخ الاحتياطي يتم تلقائياً في الخلفية.

## ملاحظة مهمة

يجب أن يكون OneDrive (المدمج مع ويندوز) أو Google Drive مثبّتاً ومسجَّلاً
دخول على جهاز العميل قبل تشغيل `install_scheduled_backup.ps1`، وإلا ستُحفظ
النسخ محلياً فقط في `backups_local_only` داخل مجلد المشروع دون رفعها للسحابة.
