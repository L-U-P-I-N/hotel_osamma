# تشغيل النظام أوفلاين + نسخ احتياطي تلقائي للسحابة + تطبيق سطح مكتب

هذه السكربتات تجعل النظام يعمل بشكل كامل بدون إنترنت على جهاز الفندق، وترفع
نسخة احتياطية تلقائياً إلى OneDrive/Google Drive كلما توفر الإنترنت، وتوفّر
تطبيق سطح مكتب حقيقي (Electron) بدل فتح متصفح.

## التثبيت على جهاز فارغ تماماً

1. افتح PowerShell **كمسؤول (Run as Administrator)**
2. نزّل المشروع أولاً:
   ```powershell
   winget install --id Git.Git -e --accept-source-agreements --accept-package-agreements
   ```
   أغلق النافذة وافتح واحدة جديدة كمسؤول، ثم:
   ```powershell
   git clone --branch main https://github.com/L-U-P-I-N/hotel_osamma.git C:\laragon\www\hotel_osamma
   ```
3. نفّذ:
   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\laragon\www\hotel_osamma\deploy\install_fresh_machine.ps1
   ```
4. انتظر حتى تظهر رسالة خضراء **"Installation complete!"**

**مهم جداً:**
- السكربت **آمن لإعادة التشغيل** — لو توقف أو فشل في أي خطوة، شغّله من جديد
  وسيكمل من حيث توقف بدل ما يبدأ من الصفر.
- كل خطوة تُسجَّل في ملف `hotel_install_log.txt` على سطح المكتب. لو ظهرت
  رسالة حمراء "FAILED"، أرسل هذا الملف لمعرفة سبب المشكلة بالضبط.
- ✅ **مُختبر بالكامل من الألف للياء** على جهاز حقيقي وينجح إلى "Installation complete!".

### لماذا لا يوجد ملف exe جاهز للتحميل من الإنترنت؟

جرّبنا تحويل السكربت لملف `.exe` مستقل (عبر أداة ps2exe) لتحميله مباشرة من
رابط — لكن ويندوز صنّفه **كفيروس** عند التحميل من المتصفح (سلوك معروف مع أي
exe غير موقّع رقمياً يقوم بأفعال شبيهة ببرامج التثبيت مثل تعديل خدمات النظام).
لذلك السكربت `.ps1` عبر PowerShell هو الطريقة الموصى بها والمُختبرة فعلياً —
ملف نصي عادي لا يُصنَّف كملف تنفيذي مشبوه.

## تطبيق سطح المكتب (بدل فتح متصفح)

السكربت يثبّت تلقائياً **تطبيق سطح مكتب حقيقي** (مبني بـ Electron) بدل
الاعتماد على المتصفح — نافذة برنامج عادية بدون شريط عنوان متصفح، تفتح تلقائياً
على النظام. لأن ملف `HotelOsamma-Desktop.exe` يأتي **ضمن نسخة git clone نفسها**
(وليس تحميلاً منفصلاً من المتصفح)، فهو **لا يواجه نفس مشكلة SmartScreen**
التي واجهها ملف ps2exe.

الاختصار على سطح المكتب باسم "نظام الفندق" يفتح هذا التطبيق تلقائياً.

### تحديث تطبيق سطح المكتب بعد أي تعديل على main.js

```powershell
cd desktop-app
npm install
npm run build
copy dist\HotelOsamma-Desktop.exe ..\deploy\HotelOsamma-Desktop.exe
```

## السحب الآلي للبيانات من النظام الأونلاين (اختياري، للمتقدمين)

بدل الضغط اليدوي على زر "تنزيل نسخة كاملة من النظام" ونقل الملف يدوياً، يمكن
للسكربت **سحب أحدث نسخة تلقائياً** لحظة التثبيت عبر نقطة API محمية برمز سري.

⚠️ **تنبيه أمني مهم**: هذا المستودع **عام (public)** على GitHub. أي رمز سري
يُكتب داخل ملفات المشروع نفسها سيكون مرئياً للجميع. لذلك الرمز **لا يُحفظ في
المستودع إطلاقاً** — فقط محلياً على جهاز الفندق.

**خطوات التفعيل (مرة واحدة):**

1. **على استضافة Laravel Cloud**: أضف متغير بيئة جديد
   ```
   BACKUP_API_TOKEN=<رمز طويل عشوائي تختاره أنت، مثلاً 40 حرف عشوائي>
   ```
   من لوحة تحكم Laravel Cloud → إعدادات المشروع → Environment Variables،
   ثم أعد نشر التطبيق (redeploy) حتى يُقرأ المتغير الجديد.

2. **على جهاز الفندق**: قبل تشغيل السكربت، أنشئ ملف نصي بهذا المسار بالضبط:
   ```
   C:\laragon\www\hotel_osamma\deploy\cloud_backup_token.txt
   ```
   ومحتواه سطر واحد فقط: نفس الرمز الذي وضعته في الخطوة السابقة.

هذا الملف مُدرَج في `.gitignore` فلن يُرفع للمستودع أبداً حتى لو نُفِّذ
`git add .` بالغلط. لو الملف غير موجود، السكربت يرجع تلقائياً للطريقة
اليدوية (البحث عن zip في Desktop/Downloads) دون أي مشكلة.

## الفكرة (النسخ الاحتياطي التلقائي للسحابة)

- التطبيق يعمل محلياً 24 ساعة عبر Apache كخدمة Windows دائمة (`HotelOsammaApache`)
  ولا يحتاج إنترنت إطلاقاً للعمل اليومي.
- كل ساعة، مهمة مجدولة تأخذ لقطة آمنة من قاعدة البيانات (لا تتأثر حتى لو كان
  أحد يستخدم النظام في نفس اللحظة) وتضعها في مجلد OneDrive/Google Drive.
- برنامج OneDrive/Google Drive نفسه يتكفّل برفعها للسحابة تلقائياً بمجرد
  توفر الإنترنت — لا حاجة لأي منطق "كشف اتصال" مخصص، وهذا أكثر أماناً وموثوقية.
- النسخة الأونلاين تبقى **نسخة احتياطية فقط** ولا يُكتب عليها مباشرة، فلا يوجد
  خطر تعارض بيانات.

## الملفات

| الملف | الوظيفة |
|---|---|
| `install_fresh_machine.ps1` | **الأداة الرئيسية** — تُثبّت كل شيء من الصفر على جهاز فارغ تماماً |
| `HotelOsamma-Desktop.exe` | تطبيق سطح المكتب (Electron) — يُنشأ تلقائياً من `desktop-app/main.js` |
| `create_desktop_shortcut.ps1` | ينشئ اختصار "نظام الفندق" على سطح المكتب (يفضّل تطبيق سطح المكتب إن وُجد، وإلا رابط متصفح) |
| `backup_snapshot.php` | يأخذ لقطة متسقة وآمنة من `database.sqlite` باستخدام أمر `VACUUM INTO` |
| `backup_to_cloud.ps1` | ينسّق النسخ الكامل → مجلد OneDrive/Google Drive، ويحتفظ بآخر 20 نسخة فقط |
| `install_scheduled_backup.ps1` | يسجّل مهمة Windows مجدولة تُشغّل `backup_to_cloud.ps1` كل ساعة |
| `import_mysql_dump.php` | يستورد بيانات النسخة الاحتياطية (يدوية أو آلية) إلى SQLite بأمان |

## ملاحظة مهمة

يجب أن يكون OneDrive (المدمج مع ويندوز) أو Google Drive مثبّتاً ومسجَّلاً
دخول على جهاز العميل، وإلا ستُحفظ النسخ محلياً فقط دون رفعها للسحابة.
